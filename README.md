# JobShield

JobShield is a job scam detection and verification assistant.

## Features

- Screenshot-based job post analysis using OCR
- Job post and recruiter message analysis
- Company and recruiter email/domain checks
- Job URL and website analysis
- Detection of payment, UPI, OTP, credential and urgency-related scam indicators
- Official vacancy verification where publicly available
- Evidence-based risk levels
- Downloadable text report
- Cyber Crime reporting guidance for India
